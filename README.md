# BREZZA — San Bernardino

Sitio web oficial de **BREZZA Complejo Residencial**, ubicado en San Bernardino, Cordillera, Paraguay.

## 🌊 Características del Proyecto

- **38 unidades habitacionales** de 2 y 3 dormitorios.
- **Amenities**: Piscina, gimnasio climatizado, quincho con parrilla, plaza para niños y terraza mirador.
- **Implantación**: 4 bloques residenciales con vistas al lago y áreas verdes.

## 🚀 Tecnologías

- **HTML5 & CSS3** (Vanilla, diseño responsivo, animaciones suaves).
- **JavaScript** (Modo oscuro/claro de cabecera, slide hero ken-burns, lightbox interactivo).
- **Formato WebP** optimizado para máxima velocidad de carga.
